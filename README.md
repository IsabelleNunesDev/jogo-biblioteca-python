# Jogo de Gerenciamento de Biblioteca  
Um jogo desenvolvido em Python no qual o jogador assume a gestão de uma biblioteca e precisa tomar decisões que afetam diferentes indicadores da instituição.

## Sobre o projeto  
O projeto simula situações que podem ocorrer na administração de uma biblioteca. A cada rodada, o jogador escolhe entre diferentes eventos e decisões, que modificam os indicadores da instituição.

Atualmente, o jogo possui três tipos de eventos:
- Aquisição: decisões relacionadas à compra de novos materiais para o acervo.
- Equipe: situações relacionadas à carga de trabalho e ao funcionamento da equipe.
- Instituição: decisões relacionadas à administração e aos recursos da biblioteca.

## Indicadores  
As decisões do jogador afetam cinco indicadores:  
💰 Orçamento  
📚 Acervo  
👥 Equipe  
🏛️ Instituição  
👤 Usuários  

Todos os indicadores começam com o valor 50 e podem aumentar ou diminuir conforme as decisões tomadas durante o jogo.
